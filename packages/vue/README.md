# @zealakit/pattern-input-vue

[English](https://github.com/zealakit/pattern-input/blob/main/packages/vue/README.md) | [Tiếng Việt](https://github.com/zealakit/pattern-input/blob/main/packages/vue/README_VI.md) | [中文](https://github.com/zealakit/pattern-input/blob/main/packages/vue/README_CN.md)

![Zealakit Pattern Input cover](https://github.com/zealakit/pattern-input/blob/main/assets/images/pattern-input-cover.jpg?raw=true)

Headless number, masked, and one-time-code behavior for Vue 3.5+. Composables and thin components share one prop-getter contract; the package ships no styles and never replaces a plain-text input.

> **Note**
> This package is a skeleton in `1.0.0-beta.1`. It exports nothing yet: composables and components land in plan 10. The prop-getter contract is described in the root README and the repository skill.

## Install

```bash
npm i @zealakit/pattern-input-vue
```

## Status

- Package: buildable, typed, SSR-safe, and packed with the internal core bundled in.
- Behavior: none yet; no API is exported before it is implemented.
