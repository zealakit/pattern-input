# @zealakit/pattern-input-vanilla

[English](https://github.com/zealakit/pattern-input/blob/main/packages/vanilla/README.md) | [Tiếng Việt](https://github.com/zealakit/pattern-input/blob/main/packages/vanilla/README_VI.md) | [中文](https://github.com/zealakit/pattern-input/blob/main/packages/vanilla/README_CN.md)

![Zealakit Pattern Input cover](https://github.com/zealakit/pattern-input/blob/main/assets/images/pattern-input-cover.jpg?raw=true)

Headless number, masked, and one-time-code behavior for Vanilla JS / TS. The adapter attaches behavior to elements you own; it ships no styles and never wraps a plain-text input.

> **Note**
> This package is a skeleton in `1.0.0-beta.1`. It exports nothing yet: the `create*` field functions land in plan 08. The prop-getter contract is described in the root README and the repository skill.

## Install

```bash
npm i @zealakit/pattern-input-vanilla
```

## Status

- Package: buildable, typed, SSR-safe, and packed with the internal core bundled in.
- Behavior: none yet; no API is exported before it is implemented.
