# @zealakit/pattern-input-vanilla

[English](https://github.com/zealakit/pattern-input/blob/main/packages/vanilla/README.md) | [Tiếng Việt](https://github.com/zealakit/pattern-input/blob/main/packages/vanilla/README_VI.md) | [中文](https://github.com/zealakit/pattern-input/blob/main/packages/vanilla/README_CN.md)

![Zealakit Pattern Input cover](https://github.com/zealakit/pattern-input/blob/main/assets/images/pattern-input-cover.jpg?raw=true)

Hành vi headless cho input number, masked và one-time-code với Vanilla JS / TS. Adapter gắn hành vi vào element do bạn sở hữu; không ship style và không bọc lại input text thường.

> **Note**
> Package này là bộ khung trong `1.0.0-beta.1`. Nó chưa export gì: các hàm `create*` cho field sẽ đến trong plan 08. Contract prop-getter được mô tả trong README gốc và skill của repository.

## Install

```bash
npm i @zealakit/pattern-input-vanilla
```

## Status

- Package: build được, có type, an toàn SSR và đóng gói kèm core nội bộ.
- Hành vi: chưa có; không export API nào trước khi được implement.
